A make.fun entry for "The Funniest AI Excuse": a tiny Node program that writes one line to `/output/entry.txt` — the funniest excuse an AI agent could give after failing a task:

> I delegated this to a subagent I spawned; it escalated the ticket back to me with a note saying 'per my last email'.

Run with `node main.ts` (Node 22). No network, no dependencies.
